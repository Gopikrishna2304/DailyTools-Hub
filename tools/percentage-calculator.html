What is this tool?

This calculator handles the four percentage questions people search for most: finding a percentage of a number, finding what percentage one number is of another, and finding the percentage increase or decrease between two values.

How to use it

  1. Pick the calculation type from the dropdown.
  2. Fill in the two numbers it asks for.
  3. Click "Calculate" to see the result instantly.

Example

"What is 20% of 250?" → enter X = 20, Y = 250, choose the first option, and the result shows 50. "80 is what percentage of 400?" → choose the second option with X = 80, Y = 400, and the result shows 20%.

Frequently Asked Questions

How do I calculate a percentage increase? +
Percentage increase = ((New Value − Old Value) / Old Value) × 100. Select "Percentage increase from X to Y" and enter your old value as X and new value as Y.
Can the result be negative? +
Yes, for the increase/decrease options — a negative result for "increase" means the value actually went down, and vice versa.
